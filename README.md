# מפת התנ״ך — מי חי בתקופה של מי?

אפליקציית Web בעברית (RTL) שמציגה את דמויות התנ״ך, המשפחות, התקופות והאירועים על ציר זמן אינטראקטיבי אחד.
הערך המרכזי: להבין **מי חי עם מי**.

## הפעלה

```bash
npm install
npm run dev      # פיתוח
npm run build    # בדיקת טיפוסים + בנייה לפרודקשן
npm run preview  # תצוגה מקדימה של הבנייה
```

## מה יש באפליקציה

| מסך | נתיב | תיאור |
| --- | --- | --- |
| עמוד הבית | `/` | Hero, חיפוש גלובלי ותצוגה מקדימה של הציר |
| ציר הזמן | `/timeline` | הציר הראשי, עם סינון, זום, גרירה ומיקוד בתקופה או בדמות |
| דמויות | `/people` | כל הדמויות במאגר, עם סינון מלא |
| משפחות | `/families`, `/families/:id` | עצי משפחה הניתנים לגרירה ולזום |
| תקופות | `/periods`, `/periods/:id` | אנשי התקופה מקובצים לפי תפקיד, ואירועיה |
| אירועים | `/events`, `/events/:id` | ציר אירועים כרונולוגי, מי היה מעורב ומי עוד חי אז |
| ספרי התנ״ך | `/books`, `/books/:id` | הדמויות שבכל ספר, ממוקמות על הציר |
| חיפוש | `/search` | חיפוש בדמויות, תקופות, אירועים, משפחות וספרים |

כרטיס הדמות נפתח כ-Side Panel במחשב וכ-Bottom Sheet במובייל, מכל מקום באפליקציה, וכולל
פרטים ומקורות, "מי חי בתקופתו?" עם סינון לפי קטגוריה, וקשרים משפחתיים.

## מודל הנתונים

```
src/types/     — חוזה הטיפוסים (Person, Period, BibleEvent, Family, Book)
src/data/      — Mock Data בקבצי TypeScript
  people/      — הדמויות, מחולקות לקבצים לפי תקופה
  periods.ts, events.ts, families.ts, books.ts
  repository.ts — שכבת הגישה לנתונים
```

**כל ה-UI ניגש לנתונים דרך `src/data/repository.ts` בלבד.** הממשק `BibleRepository`
מוגדר עם פונקציות אסינכרוניות, כך שהחלפת ה-Mock ב-API או ב-Database לא תדרוש שינוי ברכיבים.
הוספת דמויות נעשית על ידי הוספת קובץ תחת `src/data/people/` ורישומו ב-`index.ts` — בלי שינוי ב-UI.

### על תאריכים ורמת ודאות

התנ״ך אינו מספק ציר תאריכים אחיד, ולכן **המערכת אינה ממציאה תאריכים**.
במקום זאת כל דמות ממוקמת על **סרגל סכמטי** (0–100) שמייצג סדר וחפיפה בלבד, ולכל דמות
שדה `certainty`:

- 🟢 `certain` — התקופה עולה במפורש מן הכתוב
- 🟡 `estimated` — משוערת לפי ההקשר ורצף הדורות
- 🔴 `unknown` — לא ניתן לקבוע

הוודאות מיוצגת גם ויזואלית על הציר (מלא / פסים / מסגרת מקווקוות), וגם בחישוב החפיפה
בין שתי דמויות ב"מי חי בתקופתו?".

### דמויות בעלות אותו שם

דמויות שונות בעלות אותו שם הן רשומות נפרדות עם מזהים שונים, ולכל אחת `fullName`
ו-`disambiguation` — למשל *חנוך בן קין* מול *חנוך בן ירד*, *נחור בן שרוג* מול *נחור אחי אברהם*,
*יהוידע הכהן* מול *יהוידע אבי בניהו*.

### היקף המאגר

המאגר כולל דמויות מכל הקטגוריות — מלכים, נביאים, כהנים ולויים, שופטים, לוחמים ושרים,
סופרים, אומנים, עבדים ושפחות, נשים וילדים, ודמויות שנזכרות פעם אחת בלבד או ברשימות יוחסין
(בנות צלפחד כחמש דמויות נפרדות, און בן פלת, יסכה, האישה החכמה מאבל, הנערה הקטנה מבית נעמן ועוד).
המבנה נבנה כדי לתמוך בהרחבה הדרגתית לכל הדמויות שבתנ״ך.
