# מפת המקורות — מי חי בתקופה של מי?

אפליקציית Web בעברית (RTL) שמציגה את דמויות התנ״ך, ימי בית שני, המשנה והתלמוד — המשפחות,
התקופות והאירועים — על ציר זמן אינטראקטיבי אחד, מאדם הראשון ועד חתימת התלמוד.
הערך המרכזי: להבין **מי חי עם מי**.

## קורפוסים

בראש האתר יש מתג קורפוס — **הכול / תנ״ך / בית שני / משנה / תלמוד** — שמסנן את ציר הזמן,
הדמויות, התקופות, האירועים, הספרייה והחיפוש, ונשמר בין ביקורים.

## שני מסלולי תקופות

לכל תקופה יש `track`, ובציר יש **שתי שורות רצועות מקבילות**:

- `era` — התקופה ההיסטורית: מי שלט ומה קרה (בית ראשון, גלות בבל, ימי הורדוס)
- `chain` — השלב במסירת התורה: מי מסר למי (הזוגות, תנאים, אמוראים)

הן חופפות בכוונה, וזו התשובה ל"אנשים חיים בין תקופות": **הלל מופיע גם תחת "ימי הורדוס"
וגם תחת "הזוגות"**. ההפרדה גם פותרת את הבלבול בין קורפוס לתקופה — `corpus` הוא היכן
הדמות מתועדת, `era` הוא מתי חיה. לכן עזרא נשאר תנ״ך אף שחי בתחילת בית שני.

## תורה, נביאים וכתובים

זו חלוקה ספרותית ולא כרונולוגית — רות היא כתובים אך מתקופת השופטים, ודוד מופיע בשמואל,
בתהילים ובדברי הימים. לכן היא אינה קורפוס אלא **פילטר "מדור"** ב-Filter Bar, שנגזר
מ-`bookIds` של הדמות (`sectionsOfPerson` ב-`src/utils/people.ts`). אותו פילטר משרת גם את
ששת סדרי המשנה והתלמוד.

## מה יש באפליקציה

| מסך | נתיב | תיאור |
| --- | --- | --- |
| עמוד הבית | `/` | Hero, חיפוש גלובלי ותצוגה מקדימה של הציר |
| ציר הזמן | `/timeline` | הציר הראשי, עם סינון, זום, גרירה ומיקוד בתקופה או בדמות |
| דמויות | `/people` | כל הדמויות במאגר, עם סינון מלא |
| משפחות | `/families`, `/families/:id` | עצי משפחה ושרשרת המסורה (רב–תלמיד), ניתנים לגרירה ולזום |
| תקופות | `/periods`, `/periods/:id` | אנשי התקופה מקובצים לפי תפקיד, ואירועיה |
| אירועים | `/events`, `/events/:id` | ציר אירועים כרונולוגי, מי היה מעורב ומי עוד חי אז |
| ספרייה | `/books`, `/books/:id` | תורה · נביאים · כתובים · ספרים חיצוניים · 63 מסכתות משנה · 37 מסכתות בבלי |
| חיפוש | `/search` | חיפוש בדמויות, תקופות, אירועים, משפחות וספרים |

כרטיס הדמות נפתח כ-Side Panel במחשב וכ-Bottom Sheet במובייל, מכל מקום באפליקציה, וכולל
פרטים ומקורות, "מי חי בתקופתו?" עם סינון לפי קטגוריה, וקשרים משפחתיים.

## מודל הנתונים

```
src/types/     — חוזה הטיפוסים (Person, Period, BibleEvent, Family, Book)
src/data/      — Mock Data בקבצי TypeScript
  people/      — הדמויות, מחולקות לקבצים לפי תקופה
  periods.ts, events.ts, families.ts, books.ts
  repository.ts — שכבת הגישה לנתונים
```

**כל ה-UI ניגש לנתונים דרך `src/data/repository.ts` בלבד.** הממשק `BibleRepository`
מוגדר עם פונקציות אסינכרוניות, כך שהחלפת ה-Mock ב-API או ב-Database לא תדרוש שינוי ברכיבים.
הוספת דמויות נעשית על ידי הוספת קובץ תחת `src/data/people/` ורישומו ב-`index.ts` — בלי שינוי ב-UI.

### על תאריכים ורמת ודאות

המקורות אינם מספקים ציר תאריכים אחיד, ולכן **המערכת אינה ממציאה תאריכים**.
במקום זאת כל דמות ממוקמת על **סרגל סכמטי** שמייצג סדר וחפיפה בלבד — 0–100 לתנ״ך,
100–148 לימי בית שני, ו-100–199 לשרשרת מסירת התורה עד חתימת התלמוד (`src/utils/axis.ts`,
שם מרוכזת כל ההמרה לאחוזי תצוגה). לכל דמות שדה `certainty`:

- 🟢 `certain` — התקופה עולה במפורש מן הכתוב
- 🟡 `estimated` — משוערת לפי ההקשר ורצף הדורות
- 🔴 `unknown` — לא ניתן לקבוע

הוודאות מיוצגת גם ויזואלית על הציר (מלא / פסים / מסגרת מקווקוות), וגם בחישוב החפיפה
בין שתי דמויות ב"מי חי בתקופתו?".

### דמויות בעלות אותו שם

דמויות שונות בעלות אותו שם הן רשומות נפרדות עם מזהים שונים, ולכל אחת `fullName`
ו-`disambiguation` — למשל *חנוך בן קין* מול *חנוך בן ירד*, *נחור בן שרוג* מול *נחור אחי אברהם*,
*יהוידע הכהן* מול *יהוידע אבי בניהו*.

### קשרים

לצד קשרי המשפחה (`father`, `mother`, `son`, `daughter`, `brother`, `sister`, `husband`, `wife`)
קיימים קשרי לימוד — `teacher`, `student`, `colleague`, `disputant`. אותו רכיב עץ
(`src/components/FamilyTree.tsx`) מרנדר את שניהם לפי `mode`: `family` או `masoret`.

### היקף המאגר

המאגר כולל דמויות מכל הקטגוריות — מלכים, נביאים, כהנים ולויים, שופטים, לוחמים ושרים,
סופרים, אומנים, עבדים ושפחות, נשים וילדים, זוגות, תנאים ונשיאים, ודמויות שנזכרות פעם אחת
בלבד או ברשימות יוחסין (בנות צלפחד כחמש דמויות נפרדות, און בן פלת, יסכה, האישה החכמה מאבל,
בבא בן בוטא, ברוריה ועוד). המבנה נבנה כדי לתמוך בהרחבה הדרגתית לכלל הדמויות.
